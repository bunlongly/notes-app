# Notes App - Frontend

Vue 3 + TypeScript + Tailwind CSS

## Setup

```bash
cd frontend/notes-app
npm install
npm run dev
```

App runs on `http://localhost:5173`

## Environment Variables

- `VITE_API_URL` - Backend API URL

## Deploy to Vercel

Set root directory to `frontend/notes-app` and add `VITE_API_URL` environment variable.
